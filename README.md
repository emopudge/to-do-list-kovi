# To-Do List: 4 квадранта

Веб-приложение для управления задачами на основе матрицы Эйзенхауэра (в интерпретации Стивена Кови). 
Визуальный стиль имитирует записи в бумажной тетради: фон в клетку, рукописные шрифты для заголовков и цветовое кодирование квадрантов.

## Идея

Все задачи делятся на 4 квадранта по приоритету:
- **Q1 (Горит):** срочно и важно. Пульсирующая рамка
- **Q2 (Растёт):** важно, но не срочно. По этому квадранту периодически всплывают напоминания.
- **Q3 (Суета):** срочно, но неважно.
- **Q4 (Пустота):** неважно и несрочно.

## Технологии

- **HTML5:** файл содержит только базовый каркас (подключение скрипта и стилей). Вся структура страницы генерируется динамически.
- **CSS3:** переменные, Flexbox, Grid, медиа-запросы для адаптивности под мобильные.
- **JavaScript (Vanilla):** работа с DOM API, Drag-and-Drop, сохранение в `localStorage`. Без сторонних фреймворков.

## Функционал

- **CRUD:** создание, редактирование (текст и дата) и удаление задач.
- **Статусы:** отметка задачи как выполненной с изменением визуального оформления.
- **Поиск и фильтрация:** поиск по названию, фильтр по статусу (все / активные / выполненные).
- **Сортировка:** по дате (возрастание/убывание), по важности (квадранту) и ручной порядок.
- **Режимы отображения:** переключение между классическим списком и матрицей 2х2.
- **Drag-and-Drop:** 
  - Перетаскивание карточек внутри списка для изменения порядка (сохраняется в `localStorage`).
  - Перетаскивание задач между квадрантами в режиме матрицы.
- **Умный импорт:** вставка списка задач простым текстом (каждая с новой строки). Встроенный алгоритм автоматически распределяет их по квадрантам на основе ключевых слов.
- **Локальное сохранение:** все данные сохраняются в браузере (переживают перезагрузку страницы).
