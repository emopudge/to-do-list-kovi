# To-Do List — 4 квадранта

Приложение для управления задачами на основе матрицы Эйзенхауэра
в интерпретации Стивена Кови. Визуальный стиль — ручные заметки
в тетрадке: стикеры, маркерные выделения, фон-клетка.

## Идея

Задачи делятся на 4 квадранта:

- Q1 — Горит (срочно + важно): пульсирующая рамка
- Q2 — Растёт (важно + несрочно): главный квадрант, периодические напоминания-тосты
- Q3 — Суета (срочно + неважно)
- Q4 — Пустота (несрочно + неважно)

## Технологии

- HTML5 — только подключение скрипта
- CSS3 — переменные, flex, grid, адаптив
- Vanilla JavaScript — DOM API, localStorage, drag-and-drop

## Функционал

- добавление, удаление, редактирование задач
- отметка выполнено с визуальным изменением
- сортировка по дате, фильтр по статусу, поиск
- сохранение в localStorage
- drag-and-drop
- квадранты Кови: бейджи, пульсация Q1, тосты Q2
- адаптив под мобильные
